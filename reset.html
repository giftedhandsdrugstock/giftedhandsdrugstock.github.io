Reset Options

Select what you want to reset. All actions require confirmation.

Reset Users
Deletes all users except admin. Admin account is protected.
Reset Orders
Deletes ALL orders from the system. This cannot be undone.
Reset Dummy Master
Reloads Dummy Master from Online Master. Clears ALL transaction logs (Issues Log, Receives Log).
Reset Sessions
Clears ALL login session history. Users will need to log in again if they are currently logged in.
⚠️ Reset Everything
Resets Users (except admin), Orders, Dummy Master + Logs, and Sessions all at once.
